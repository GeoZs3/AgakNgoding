## Panel Admin / Monitor

Pengguna dapat membuka halaman autentikasi khusus lewat tombol **Login Monitor** di beranda.
Administrator dapat membuka panel melalui menu **Admin / Monitor** atau `/admin`.
Panel ini menampilkan ringkasan inventaris, persentase kategori, status akun P, serta
form untuk membuat, menghapus, dan memperbarui username, role, status, serta password akun.
Status login P ditandai aktif jika ada sesi yang mengirim aktivitas dalam dua menit terakhir.

Role **P** dan **Guru** dapat mengedit data tanaman. **Admin** juga dapat mengedit tanaman,
membuka seluruh menu monitor, serta mengelola akun dan password semua pengguna. Semua akun Admin
memiliki kewenangan yang sama; akun admin aktif terakhir tidak dapat dinonaktifkan atau dihapus.
Pengguna dapat mengganti password sendiri dari menu **Ganti Password** dengan memasukkan password
saat ini, sedangkan Admin dapat mengatur password baru untuk akun mana pun dari panel monitor.
